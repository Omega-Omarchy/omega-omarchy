# Omega Omarchy 0.1.0 — technical alpha

Private development alpha. Not a release candidate. Not announced, not
submitted, not published as a public service.

What this pass actually demonstrates:

- *Make It Come Alive* is now the preserved Ultra music master for a complete
  first audio-system pass: deterministic Ultra/High/sixteen-bit music and SFX,
  semantic cue manifest, scene switching, streamed music, bounded voices,
  independent Pause/installer sound quality, mixer buses, captions, save
  migration, no-device fallback, and browser gesture unlock. Public music
  redistribution rights and human listening approval remain explicit gates.

- The browser output now runs the authoritative Pygame simulation and renderer
  instead of a separate canvas mock-up. It packages Chapter 1/Cow assets in a
  fast stored archive, emits Ogg audio, persists saves through localStorage,
  and has passed installer/keyboard smoke testing in desktop Chromium.
- The sound-support design now documents the implemented master-to-runtime
  system and keeps authored re-orchestration, pack audio, and listening/browser
  qualification visible as later work.
- Contributor setup now includes a non-destructive `doctor`, a loopback web
  server command, a focused web test scope, web issue labeling, and a dedicated
  browser troubleshooting/smoke guide.

- Five Omega Omarchy emblem concepts derived from a shared rough-metal,
  Omarchy-green Omega brief. Powered Artifact is now the selected master shown
  in the README and used for deterministic native-window and browser icons.
- F2 stages the current chapter exactly 15 tiles left of its generated boss;
  F4 switches to the final chapter and applies the same geometry-relative
  placement for Goliath.
- The Goliath scaffold is now a four-stage field/RPG encounter: an enormous
  remote cyborg penguin controlled from an elevated booth, the existing direct
  Goliath exchange, a placeholder X block notice with two proxy minions, and
  surrender only after both proxies are defeated. Phase state is saved.
- Goliath's first two phases fire at one-quarter their previous rate. Float-safe
  minion patrol eliminates the phase-three indexing crash seen in playtesting.
- Pivot platforms derive leverage from the player's actual contact patch, so
  even a one-pixel overlap at either far end contributes full-direction torque.
- Checkpoint retry reopens and rearms boss gates, and both player and helper
  projectiles stop at closing or closed gate panels.
- Issue-dependent developer verification: exact pytest selectors and maintained
  subsystem scopes are the normal workflow, while `release-check` remains the
  explicit full asset/pack/test/identity/native-smoke/web gate. A bare script or
  bare `test` command no longer runs the entire suite unexpectedly.
- Gust jumps now receive the ordinary grounded jump impulse; cannon entry has a
  larger airborne capture area and a post-entry input lock requiring a fresh
  Jump press. The cannon landing no longer emits a redundant completion status.
- RPG action copy uses a dedicated three-line field, and neutral beats visibly
  separate player, helper, and foe actions without shortening their writing.
- The doorway-recession party now ends 25% smaller than its previous destination
  scale while retaining its continuous grounded path into the door.
- The standalone Code of Conduct was removed by maintainer direction. DCO,
  provenance, governance, triage, and private security reporting remain scoped
  to their specific jobs.

- A usable installer whose choices (character, seed, difficulty, accessibility,
  art fidelity, independent sound fidelity, display, Limitless, sharing) are
  selectable and bound into the generated session/world as appropriate
- **Play Now** as the completion action
- Six large deterministic procedural macro-route maps with multi-screen
  vertical ladder, bumper, and platform routes, with the first chapter
  golden-path qualified for movement, penguins, blocks, a Logic Bomb,
  action and turn-based conversion combat, and a boss that ordinary keys can
  convert. The default path now ends on a dedicated Chapter 1 completion and
  credits surface; later development chapters require an explicit R/Y opt-in.
- OMARCHY-logo fly-out and fly-back transitions plus viewport-bounded,
  multi-tile over-the-shoulder editing with a staged high reward, using a
  dedicated looking-away model separate from traversal and climbing art.
  Placement/removal now previews live, with single-step undo and full reset
  before validation and sealing.
- Authored idle, four-phase walk, jump/fall/land, item/attack jump, and
  four-phase back-climb art
  across the fidelity tiers
- A SNES-class 64-color baseline, 256-color 32-bit-era High treatment, and
  unquantized modeled pre-rendered Ultra treatment at 1×/2×/3× raster density
  without changing collision space
- Six original Ultra panorama masters; Ultra-textured tiles, ladders, gates,
  bumpers, cracked kick tiles; seven items; six boss-motif enemy families; and
  oversized bosses
- Zelda-like C/X header slots with David's shoe, projectile item use, source
  score popups, air-jump/rush/crouch-slide combination moves, persistent
  ladder grip, fast ladder slides, terminal-input guards, walkable ladder/deck
  crossings, and platform-aware ladder dismounts
- Correct gamepad edge handling for D-pad/stick menu navigation and rushes,
  Start pause, Back/View customization, hot-plug identity, and multiple-pad
  input aggregation
- A player-facing Pause → Controls remapper for primary/alternate keyboard
  bindings and physical gamepad action buttons, with conflict swaps, per-binding
  and device resets, last-active-device binding prompts, save/reroll persistence,
  and per-fidelity render inspection
- Player-visible BS-overload recovery with a checkpoint retry and disclosed
  score deduction, plus a two-step, default-No world reroll that generates the
  successor before swapping state and archives the previous sealed world as a
  validated save
- Pause menu: normalized current-direction portrait, full item/attack loadout,
  save/load, Limitless customize, audio mute
- Direct-contact JRPG conversion combat with David idle on the left, enlarged
  foes on the right, R Reuse, real enemy turns, BS meters, floating deltas,
  dedicated battle staging, spatially separated recruited helpers, flashed
  actor cues, delayed player/helper/foe turns, and no duplicate traversal avatar
- Independently adjustable CRT scanline size/depth, curvature, and phosphor
  bloom without RGB channel tint. Curvature uses cached SDL row-band transforms
  rather than a per-frame full-resolution NumPy remap, and static overlays are
  reused across frames.
- Official Omarchy logo geometry in the installer and HUD, oligarchy.fyi's
  block-geometry OLIGARCHY mark after the event, the offset OMEGA title
  modifier, and edge-triggered Return submission
- An eight-beat, skippable in-engine title prologue with Mega Man-style text-box
  exposition, an implied circular "spaceship" campus, capture, consciousness
  transfer, and corrupt-install handoff into play
- A six-node boss route screen between chapters, plus authored field movement
  and named projectile abilities for every boss before RPG contact
- Three cross-system score chains; five collectible O-M-E-G-A hardware blocks
  rendered above the OMARCHY HUD mark; and a spawned, Up-activated secret door
  into a 236×36 Cow Level with bumpers, gusts, launch-trajectory rewards near
  the cannon and denser conventional rewards beyond them,
  seven instant-convert cow/llama helpers, and an oversized aim/charge cannon
  whose ballistic state can smash even ordinarily unbreakable tiles
- RPG intent/counter telegraphs and named David/helper combinations, including
  side-view talking-point redirection by Detractabot
- A finite, non-wrapping pre-rendered panorama; generated material UI frames;
  fitted/ellipsized interface text; and a staged JRPG battle layout
- Indoor Corrupted Install and computer-hardware Distro Front panoramas derived
  into every fidelity tier. Distro Front adds a true-alpha foreground component
  plane, four physically separated hardware regions, bidirectional Ethernet and
  Wi-Fi portals, six unique seeded connection operations, and a brief dedicated
  network-traversal interstitial.
- Three fly-out-edit pickups in every pre-Oligarchy chapter (four in the forced
  Chapter 1 QA fixture), plus a surface-registered slide that returns to a
  standing idle lock when its held combo has exhausted momentum.
- Distro Front's hardware regions are now four independently mounted runtime
  maps rather than one traversable canvas. Arrival portals require a complete
  exit and re-entry before reactivation, while the unique foreground overlay
  moves faster than the playfield on both axes.
- Generated routes now include rider-weighted 4–6-tile pivot platforms, moving
  lifts, and updraft columns. Corrupted Matrix-code pits and talking-point
  impacts drain a clamped score, while tool pickups fill a capped strength meter
  that scales both side-view and RPG item effects.
- Edit pickups enforce a two-tile ladder moat, floating OMARCHY blocks enforce
  vertical clearance, the edit cursor has a slower repeat and tile-art preview,
  and the over-the-shoulder/slide silhouettes are grounded lower in frame.
- Deterministic world identity for a pinned seed
- Linux native pygame-ce play target
- Runtime asset generation removed: measured installer launch is 0.77 seconds;
  the 46-second production-art build is explicit/offline only
- A playable Chapter 1 browser alpha using the native simulation and renderer
- A versioned, data-only Chapter 1 content-pack loader with explicit activation,
  deterministic add-on ordering, canonical digests, exact save compatibility,
  a fail-closed validator/sealer, and a maintained Vertical Garden example. A
  consent-gated native lifecycle reviews sealed directories or ZIPs, installs
  them disabled into game-owned storage, and supports list, enable, disable,
  and remove with revalidation at use. This remains a narrow generation-profile
  surface; later content and custom assets remain outside the supported contract.
- An 83 MB-class portable Linux player bundle that embeds Python and native
  runtime dependencies, excludes production-source masters and optional
  Limitless code, records commit/dependency/asset identities, includes player
  docs and provisional rights notices, publishes a SHA-256 file, and is safely
  extracted plus headless-smoke-tested by a dedicated verifier. Its v2 archive
  preserves only independently validated in-root PyInstaller library links,
  avoiding duplicated native payload.
- A read-only-permission GitHub CI definition and the tracked
  contributor surface: governance, roadmap, DCO, security policy,
  contribution guide, issue-dependent verification protocol, triage taxonomy,
  five issue forms, and evidence-focused pull-request template. Hosted
  default-branch CI is green; pull-request execution, branch protection,
  applied labels, and a dry-run external contribution remain cutover evidence
  gaps.
- A redacting release-audit pipeline inventories reachable refs/history,
  current files, commit identities/messages, large binaries, source/wheel/native
  and web artifacts, source maps, SPDX packages, bundled libraries, and pinned
  Python advisories without reproducing matched values. The first preflight
  found no credential signatures, remediated current temporary paths and 19
  unique dependency advisories, and leaves one historical machine-path
  fingerprint plus independent/native review explicitly open.
- Synthesized WAV generation now uses fixed-point phase, envelope, mixing, and
  PCM conversion. This removes Python/NumPy/libm rounding drift from the tracked
  audio gate while preserving sample rate, duration, bounds, and retro timbre.
