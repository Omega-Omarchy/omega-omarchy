# Omega Omarchy social card samples

Four review candidates created 2026-09-11 with Codex's **built-in image-generation tool**, using accepted Omega Omarchy art as references. These are generated marketing compositions, not unedited gameplay screenshots. Jeremy Dixon selected **04 — One choice? Think again.** on 2026-09-11. Its X and Open Graph exports are installed in the website metadata.

Open `index.html` for the comparison gallery. Select **My pick**, inspect feed width and light/dark surrounds, and download the artwork. Selections stay in browser local storage; **Save my selection** downloads a text note and sends nothing externally.

## Export recipe

For each direction:

```sh
convert CARD-master.png -resize 1200x600 CARD-x.png
convert CARD-x.png -background '#13151d' -gravity center -extent 1200x630 CARD-og.png
```

Artwork follows the repository's existing asset license classification. The reference wordmark and font branding provenance remain documented in the game's branding notices.
