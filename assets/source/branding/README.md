# Omarchy logo source

`omarchy-logo-official.png` is a rasterized copy of the official `logo.svg`
from the [Basecamp Omarchy repository](https://github.com/basecamp/omarchy),
retrieved on 2026-08-28. The asset build applies the local theme color without
altering the mark's geometry.

`oligarchy-logo-official.png` is a rasterized copy of the inline block-geometry
SVG currently used by [oligarchy.fyi](https://oligarchy.fyi/), retrieved on
2026-08-29. The asset build likewise preserves its alpha geometry and applies
the local theme color. It is vendored separately from the game's blanket code
license so the eventual public cutover can resolve branding rights explicitly.

`omega-omarchy-logo-concepts/` contains five original rough-metal Omega emblem
directions produced for maintainer review. The second, Powered Artifact, was
selected on 2026-09-02 and promoted unchanged to
`omega-omarchy-logo-powered-artifact.png`. Deterministic mask-safe application
icons are derived from that master; its local inspiration image is not
versioned. The concept manifest records the generation and rights-review
boundary.
