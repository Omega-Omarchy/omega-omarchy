# Omega Omarchy logo concepts

These five September 2026 exploration masters began as review candidates. The
maintainer selected variant 2, Powered Artifact, on 2026-09-02; the canonical
unchanged master now lives one directory up as
`omega-omarchy-logo-powered-artifact.png`. They were generated with OpenAI's
built-in image-generation workflow using `quake-1-logo.jpg` from the
maintainer's local transfer inbox as visual inspiration only. That external
reference is not copied into this repository.

The shared prompt contract requested an original, complete circular Omega
Omarchy emblem with no lower spike; rough forged metal shifted toward Omarchy
green; a distinct uppercase Greek omega inside the ring; a centered square
app-icon composition; true-alpha exterior; no words, mockup, scenery,
recognizable franchise geometry, or copied Quake glyph. One generated result
was retained for each direction:

1. `variant-01-ancient-forged.png` — pitted archaeological bronze and green
   mineral oxidation.
2. `variant-02-powered-artifact.png` — blackened machine metal, green energy,
   and an energized inset omega.
3. `variant-03-architectural.png` — monumental machined ring, beveled omega,
   and restrained emerald illumination.
4. `variant-04-modern-rugged.png` — cleanest small-icon silhouette with rough
   gunmetal facets and vivid green edge light.
5. `variant-05-machine-shrine.png` — the densest mechanical construction, with
   ancient-machine wear and a luminous omega core.

Variants 3 and 5 received a final background-removal edit because the first
outputs visually depicted a checker studio plate. All five checked-in files
have real RGBA transparency. The selected master now has deterministic 32, 64,
128, 256, and 512-pixel mask-safe derivatives used by the native window and
web-preview favicon. The project's branding/rights review remains an explicit
gate before release.
